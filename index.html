How to Use Intuiva

Getting Started

Answer the questionnaire to let AI analyze your project goals and generate relevant tasks. Your work is automatically saved locally.

Kanban Board Features

  • Drag & Drop: Move tasks between columns to update status
  • Task Actions: Click task title to edit, hover for action buttons
  • Priority Colors: Color-coded priorities help focus
  • Auto-Save: Projects save automatically every 30 seconds

AI Features

  • Smart Tasks: AI generates tasks based on your answers
  • Project Reports: Generate 1-page professional reports
  • Regenerate: Get new task suggestions anytime
  • PDF Export: Download project reports as PDF

Data Storage

  • Local Storage: Projects save to your browser
  • Export/Import: Backup projects as JSON files
  • Warning: Clearing browser data deletes projects
  • Multiple Projects: Save and switch between projects

Pro Tips

  • Use detailed answers for better AI analysis
  • Export projects regularly for backup
  • Use tags to organize tasks
  • Generate reports before meetings
  • Try both light/dark themes for comfort
